The repo describe a pipeline to create a feed on the AT protocol. 

There are 2 components to this: 1) candidate generation/retrieval to create the inventory, and 2) ranking

The idea is to organize code in feature extraction steps, that we can run on a pinned snapshot of the network, and features get stored and indexed in Postgres for ranking. 

`docs/tutorial-new-feature-and-ranker.md` describes how to modify the ranker part of the pipeline
